# CEO Daily Runtime

A time-blocked daily schedule tracker for high-performance founders.

## Features
- Live clock + current-task highlight
- Add / delete time blocks (persisted in localStorage)
- Export schedule as `.ics` (native phone alarm via calendar)
- QR-code sync (pure client-side, no server)

## Run
Open `index.html` in a browser. That's it — no build step.

## Files
- `index.html` — markup
- `style.css` — dark corporate theme
- `script.js` — logic + iCal generator
